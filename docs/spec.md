# 539 尾數觀察站 規格書（程式計畫書）

線上完整版（有手機畫面圖）：https://claude.ai/code/artifact/0784f2f0-a4b6-4e68-a511-55b9c62d38f4
這份是給 Claude Code 讀的文字版，兩份內容相同。

## 目標
1. 手機一鍵打開，操作像 app（全螢幕、底部導覽列、可加到主畫面）
2. 開獎資料每天自動更新，親友打開就看到同一份最新資料
3. 公司網路、沒有 claude.ai 帳號的人也能用（所以不放 claude.ai，改放 GitHub Pages）

## 架構
- 後端：Google Sheet「539 開獎資料」，工作表 draws（A 欄日期純文字 yyyy-MM-dd，B–F 欄 5 個號碼）+ 綁在上面的 Apps Script（gas/Code.gs）
  - doGet()：回傳 {"draws":[{"d":"2026-10-06","n":[14,25,26,29,33]}, ...]}
  - dailyUpdate()：時間觸發器每晚 9–10 點執行，抓兩個開獎網站，兩邊號碼一致才寫入
    - https://www.pilio.idv.tw/lto539/list.asp
    - https://www.lotto-8.com/listlto539.asp
  - doPost()：匯入官方 CSV、刪除一期，要密碼（密碼存在指令碼屬性 ADMIN_PASSWORD）
- 前端：GitHub Pages 上的 PWA（app/ 資料夾）
  - app.js 的 loadDraws()：向 doGet 拿資料，存一份在 localStorage；沒網路就用上次的
  - stats.js：從 reference/539-tail.html 搬過來的計算函式，公式不改
  - manifest.json + sw.js：可加到主畫面、離線可開

## 功能（全部沿用 reference/539-tail.html）
統計範圍可選近 10、15、20、25、30、100、300 期或全部。
- 尾數分布：各尾數次數、與理論值差 %、卡方值（門檻 16.9）。理論值 = 期數 × 5 × 號碼數 ÷ 39，尾 0 有 3 個號碼、其他 4 個
- 交叉比對：近 30 與近 100 期各自用 z 分數排名，兩邊都在最冷 3 名 = 雙冷
- 遺漏期數、熱冷走勢（近 60 期熱力圖）
- 單號冷熱（39 號卡方門檻 53.4）、連莊（理論平均 0.641 個）、組合特徵（和值、奇偶、大小、連號）
- 選號回測：7 種策略，每期只用該期之前的資料
- 期望值：每注稅前期望 27.92 元（回收率 56%）、1,000 人模擬

## 開發階段（一次做一個，驗收過才做下一個）
1. 資料後端：寫 gas/Code.gs（doGet、dailyUpdate、doPost，加一個 testParse 用來看兩個網站各抓到幾期）。我自己建 Sheet、匯入 data/539-draws.csv、貼程式、設觸發器、部署，拿到 /exec 網址。
2. 搬移前端：把 reference/539-tail.html 拆成 app/ 底下的 index.html、style.css、app.js、stats.js，資料改從 /exec 網址讀，加離線快取。我上傳到 GitHub 倉庫 539-app，開 GitHub Pages。
3. 變成手機 app：加 manifest.json、sw.js、icons（192、512 px），改成底部導覽列。
4. 細節：管理者模式（密碼）、顯示資料更新日期（超過 2 個開獎日沒更新就提醒）、下拉重新整理。

## 風險
- 開獎網站改版 → 抓不到只會不寫，不會寫錯；app 頂端顯示更新日期，卡住就調整解析規則
- 兩個網站剛好都寫錯 → 每隔幾個月匯入台彩官方 CSV 覆蓋
- 中獎稅金門檻有「超過 5,000 元」和「超過 2 萬元」兩種說法，上線前到台彩官網確認
